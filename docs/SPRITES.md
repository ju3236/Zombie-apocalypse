# 도트 리소스 규격 (거점 화면)

거점은 **평면 도트 아이소메트릭**이다. 모든 그림은 **1배(원본) 크기**로 그리고, 게임이 정수배(×1~×6)로 키워서 보여 준다.
안티에일리어싱 없이, 배경은 **투명 PNG**로 그린다.

> `docs/sprite-templates/` 에 지금 게임에 들어가 있는 임시 그림이 **정확한 크기**로 들어 있다. 그 위에 덧그리면 크기·위치가 바로 맞는다.
> `docs/sprite-templates/guide/` 는 4배로 키우고 **바닥 자리(빨간 마름모)** 를 표시한 참고용 그림이다 (게임에 넣는 파일 아님).

## 1. 바닥 타일 한 칸

```
        16px
   ┌─────/\─────┐
   │   /    \   │ 16px     타일 = 가로 32 × 세로 16 마름모 (2:1)
   │ /        \ │          가로 1칸 이동 = 오른쪽 16, 아래 8
   │ \        / │          세로 1칸 이동 = 왼쪽 16, 아래 8
   │   \    /   │
   └─────\/─────┘
        32px
```

## 2. 가구

| 규칙 | 값 |
|---|---|
| 그림 **가로** | `(가로칸 + 세로칸) × 16` px — 딱 이 값 |
| 그림 **세로** | 자유. 높은 가구는 위로 늘리면 된다 |
| 기준점(바닥에 닿는 곳) | 그림 **맨 아래 `(가로칸 + 세로칸) × 8` 줄**이 바닥 마름모. 마름모의 아래 꼭짓점 = 그림의 맨 아래 줄 |
| 바닥 마름모 꼭짓점 (그림 높이 H) | 위 `(세로칸×16, H−(가로+세로)×8)` · 오른쪽 `((가로+세로)×16, H−세로칸×8)` · 아래 `(가로칸×16, H)` · 왼쪽 `(0, H−가로칸×8)` |
| 방향 | 기본(회전 0)은 **정면이 오른쪽 아래(↘)를 보는** 모습. 가로칸이 오른쪽 아래, 세로칸이 왼쪽 아래로 뻗는다 |
| 회전 | 회전하면 **자동 좌우 반전**. 반대쪽 모습을 따로 그리고 싶으면 `키_r1.png` 를 같이 넣는다 (예 `furn_bed_r1.png`, 가로 크기 같음) |
| 그림자 | 넣지 않는다 (게임이 그림) |

## 3. 벽 · 벽지 · 문 · 창문

벽은 **정면에서 본 납작한 직사각형 16 × 70** 으로 그린다 (벽 한 칸의 한 면).
게임이 이걸 비스듬히 기울여서 ↘ 방향 벽, ↙ 방향 벽(조금 어둡게)을 둘 다 만든다. 윗면 마감도 게임이 그린다.
앞쪽 벽은 실내가 보이도록 아래 6px 만 잘라 쓰므로, **바닥 쪽 6px 에는 걸레받이처럼 어울리는 색**을 두면 좋다.

| `wall_wood` | 나무 벽 | 벽/문/창 | 16×70 |
| `wall_paper_flower` | 꽃무늬 벽지 | 벽/문/창 | 16×70 |

## 4. 캐릭터

* 크기 **26 × 38** 권장 (최대 64 × 96), 투명 PNG
* **발 = 그림 맨 아래 줄 가운데**. 그 점이 칸 중앙에 선다
* 오른쪽 아래(↘)를 보는 모습으로. 왼쪽으로 걸을 때는 자동 좌우 반전
* 게임 안에서 **생존자 → 프로필·일지 → 편집 → 그림 올리기** 로 캐릭터마다 넣을 수 있다 (같이 사는 친구에게도 보임)

## 5. 소품 (가구 위에 올리는 것)

* **12 × 12**, 아래 가운데가 가구 윗면에 놓인다
* 키: `prop_p_mug` 머그컵, `prop_p_teddy` 곰인형, `prop_p_photo` 사진 액자, `prop_p_candle` 양초, `prop_p_book` 소설책, `prop_p_radio` 라디오, `prop_p_vase` 꽃병, `prop_p_gameboy` 휴대용 게임기, `prop_p_flowers` 조화 꽃다발, `prop_p_cactus` 선인장 화분, `prop_p_perfume` 향수병, `prop_p_cat_plush` 고양이 인형, `prop_p_music_box` 오르골, `prop_p_snowglobe` 스노볼, `prop_p_clock` 탁상시계, `prop_p_figurine` 피규어, `prop_p_lp` LP 레코드, `prop_p_trophy` 트로피, `prop_p_pet_bowl` 반려동물 밥그릇, `prop_p_globe` 지구본

## 6. 게임에 넣는 법

1. PNG 를 `public/assets/` 아래에 둔다. 예) `public/assets/furniture/furn_bed.png`
2. `src/phaser/assetManifest.ts` 에 한 줄 추가

```ts
export const ASSET_MANIFEST: Record<string, string> = {
  furn_bed: 'assets/furniture/furn_bed.png',
  furn_bed_r1: 'assets/furniture/furn_bed_r1.png', // (선택) 회전한 모습
  wall_concrete: 'assets/walls/wall_concrete.png',
  floor_wood: 'assets/floors/floor_wood.png',
  prop_p_mug: 'assets/props/p_mug.png',
};
```

등록 안 된 키는 임시 그림이 그대로 쓰이므로 **하나씩 바꿔 나가도 된다**.
