# 🧟 끝나지 않는 피난처

엔딩 없는 2인용 좀비 아포칼립스 생존 샌드박스 웹게임 — **첫 번째 플레이 가능 버전 (v0.1)**

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 생성 → Cloudflare Pages 등에 정적 배포
```

## 지금 실제로 동작하는 것

| 영역 | 내용 |
| --- | --- |
| 캐릭터 | 자캐 등록(이름·나이·직업·외형 색상·설정), 여러 캐릭터 전환 조종, 직업별 시작 숙련도, 8종 숙련도 성장, 영구 사망 오너 허용제(기본 꺼짐 → 쓰러지면 동료가 구조) |
| 생존 | 체력·포만·수분·기력·감염·부상(긁힘/열상/물림)·소지 무게, 붕대·소독·항생제, 거점 자동 식사(설정) |
| 거점 (Phaser) | 2D 타일 공간, 캐릭터 자동 생활(배회·앉기·잠자기·작업 위치 이동), 조종 캐릭터 클릭 이동, 가구 배치·회전·이동·회수, 책상/선반 위 소품 진열, 벽·문·창문·벽지·바닥재 건설(드래그), 철거, 부지 확장, 개인 침대 소유자, 밤 어둠 + 조명 |
| 시설 | 작업대·스토브·의료 캐비닛(제작 조건), 빗물 수집통·텃밭(실시간 생산, 오프라인 진행) |
| 월드 | 고정 시드로 생성되는 오리지널 도시 지도(360×320 타일): 강·항구·해안·순환도로·철도·중앙대공원·농지·숲. 15개 대분류 · 약 170종 소분류 · 218개 장소, 드래그/휠 확대 지도, 검색, 구역 필터, 특수·비밀구역은 발견해야 표시 |
| 탐험 | 거리 기반 이동 시간, 구역 이동, 잠긴 구역(쇠지렛대=시끄러움 / 자물쇠 따기=실패 가능 / 열쇠), 숨은 공간 발견, 꼼꼼히·빠르게 수색 선택, 소음 게이지, 어두운 곳(손전등), 수색 중 사건, 고갈과 느린 재보급, 지역 지도로 새 장소 발견, 연구소 출입카드 |
| 전투 | 기습·공격·밀치기·숨기·도주, 무기별 피해/명중/소음/내구도, 탄약, 좀비 종류 3종, 소음에 따른 증원 |
| 제작 | 30개 제작법(무기·도구·의료·요리·가구·건축 자재·시설), 도구/시설/숙련도 조건, 무기 수리 |
| 채팅 | 조종 중인 캐릭터로 채팅(말풍선 표시)·편지, 치료하기·함께 앉기·부축하기·선물, 오너가 직접 쓰는 관계, 개인 일지, 로그 TXT 저장 |
| 저장 | 자동 저장(localStorage), 세이브 파일 내보내기/가져오기, 2인 플레이어 이름 구분 |
| 같이 살기 | Firebase Realtime Database 로 같은 월드·거점을 실시간 공유. 한 사람이 올리고 초대 코드를 보내면 친구가 참가. 섹션별 동기화(캐릭터·탐험·거점·창고 등), 채팅·소식은 합치기, 접속자 표시, 재접속 시 자동 연결 |

오프라인 원칙: 접속하지 않는 동안 **게임 시간은 흐르지 않는다** (굶거나 다치지 않음). 실제 시간으로는 빗물·텃밭 같은 안전한 생산만 진행된다. 위험한 사건은 플레이 중 탐험에서만 일어난다.

## 구조

```
src/
  game/                 순수 게임 로직 (UI·렌더러와 분리)
    data/               아이템·가구·장소·제작법·직업 데이터 (여기만 고치면 콘텐츠 추가)
    world/              도시 생성기(cityGen) · 15개 구역과 소분류·루트 테이블(districts)
    systems/            time / character / expedition / crafting / base / rp
    store.ts            전역 상태 + 자동 저장 + 세션(현재 플레이어, 조종 캐릭터)
    persistence.ts      SaveAdapter 인터페이스 (Local → Firebase 교체 지점)
  phaser/
    BaseScene.ts        아이소메트릭 거점 렌더링, 캐릭터 AI, 배치/건축 입력
    isoTextures.ts      아이소메트릭 임시 텍스처 (바닥 마름모, 벽 블록, 가구 상자)
    textures.ts         임시 도형 스프라이트 생성
    assetManifest.ts    ★ PNG 도트 리소스 교체 지점
  ui/                   React 화면들
```

### 그래픽 교체

`public/assets/` 에 PNG 를 넣고 `src/phaser/assetManifest.ts` 에 `스프라이트키: 경로` 를 적으면 해당 임시 도형이 대체된다. 키 이름과 크기 규칙은 파일 상단 주석 참고 (1타일 = 32px, 캐릭터 파츠는 흰색으로 그리면 색이 입혀짐).

### 같이 살기 (Firebase)

`src/game/online.ts`. 설정 → 같이 살기에서 Firebase 웹 앱 설정을 붙여넣으면 월드를 올리고 초대 코드를 만든다. Realtime Database 규칙 예시는 설정 화면 안내에 있다. 로컬 테스트는 Firebase 에뮬레이터(`emulator: "127.0.0.1:9000"`)로 할 수 있다.
